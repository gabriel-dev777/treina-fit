# Treinna Fit Landing Page

Landing page premium para a Treinna Fit, com foco em visual cinematográfico, animações GSAP, navegação fluida e conversão comercial.

## Estrutura

- `index.html` — estrutura principal do site
- `assets/css/` — estilos, reset, animações e responsividade
- `assets/js/` — dados, animações e interações
- `assets/images/` — imagens locais e materiais de marca
- `assets/videos/` — vídeos locais, se houver
- `assets/icons/` — ícones e assets visuais

## Execução local

```bash
cd c:\treinafit
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## Personalização

- Ajuste textos, contatos e links em `index.html`
- Edite `assets/js/data.js` para centralizar mensagens e links
- Atualize imagens e paleta em `assets/css/style.css`
- Mantenha anotações de materiais provisórios no código quando dependentes de confirmação do cliente

## Observações

- O projeto usa CDN para fontes e bibliotecas JS (GSAP, SplitType, Lenis)
- O conteúdo foi escrito com foco em dados confirmados e marcações provisórias quando a informação ainda depende de validação do cliente
